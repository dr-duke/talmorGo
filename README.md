<h1 align="center">TalmorGo</h1>

<p align="center">Telegram-бот и веб-интерфейс для скачивания видео через <a href="https://github.com/yt-dlp/yt-dlp">yt-dlp</a> с хранением на локальном диске.</p>

---

## Возможности

- **Telegram-бот** — добавление ссылок в очередь, статус очереди, поиск, постоянные ссылки на файлы
- **Веб-интерфейс** — медиатека с поиском и фильтрами, встроенный плеер видео и аудио,
  переименование, теги и коллекции, постоянные ссылки
- **Плейлисты и каналы** — разворачиваются в отдельные задания автоматически
- **Извлечение аудио** — дорожка вытаскивается через ffmpeg, ID3-теги правятся из интерфейса
- **Фоновые операции** — массовые действия и обслуживание идут в очереди с отдельной полосой
  для тяжёлых задач; их видно и можно прервать
- **Retry с backoff** — неудачные загрузки повторяются до суток, затем `failed`; ручной сброс из интерфейса
- **Импорт из директории** — DirScanner подхватывает файлы, появившиеся на диске
- **HTTP / SOCKS5 прокси** — для yt-dlp и Telegram-бота независимо

## Стек

| Слой | Технология |
|------|-----------|
| Бэкенд | Go 1.26, SQLite (`modernc.org/sqlite`, WAL) |
| Фронтенд | HTMX + [templ](https://github.com/a-h/templ), Plyr.js |
| Скачивание | yt-dlp + ffmpeg (внешние бинари) |
| Деплой | Docker Compose / Kubernetes |

Устройство системы описано в [docs/SPEC.md](docs/SPEC.md), планы — в [docs/TODO.md](docs/TODO.md).

## Быстрый старт (Docker Compose)

```yaml
services:
  talmor:
    image: ghcr.io/dr-duke/talmorgo:latest
    environment:
      TELEGRAM_BOT_TOKEN: "your-token"
      TELEGRAM_ALLOWED_IDS: "123456789"
      BASE_URL: "https://media.example.com"
    volumes:
      - ./data:/data
    ports:
      - "8080:8080"
```

## Конфигурация

Все параметры задаются переменными окружения.

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `TELEGRAM_BOT_TOKEN` | — | Токен бота (обязателен) |
| `TELEGRAM_ALLOWED_IDS` | — | Разрешённые Telegram ID через `;` |
| `TELEGRAM_PROXY` | — | HTTP/SOCKS5 прокси для бота |
| `BASE_URL` | — | Публичный URL сервиса (для ссылок) |
| `BASE_PATH` | — | Префикс пути, если не в корне (`/talmor`) |
| `SITE_NAME` | `TalmorGo` | Название в шапке веб-интерфейса |
| `HTTP_PORT` | `8080` | Порт HTTP-сервера |
| `WEB_TOKEN` | — | Токен доступа; вход по форме `/login` или заголовком `Authorization: Bearer` |
| `DB_PATH` | `/data/talmor.db` | Путь к базе данных |
| `HTTP_HOST` | — | Адрес прослушивания (по умолчанию все интерфейсы) |
| `HEALTH_ENDPOINT` | `/health` | Путь health-check; пусто — не регистрируется |
| `TELEGRAM_DEBUG` | `false` | Подробные логи бота |
| `YT_DLP_BINARY` | `/usr/bin/yt-dlp` | Путь к бинарю yt-dlp |
| `YT_DLP_OUTPUT_DIR` | `/data` | Директория для скачанных файлов |
| `YT_DLP_OUTPUT_FORMAT` | `mp4` | Формат видео |
| `YT_DLP_PROXY` | — | HTTP/SOCKS5 прокси для yt-dlp |
| `YT_DLP_TIMEOUT` | `300` | Таймаут одной загрузки (сек) |
| `YT_DLP_EXTRA_ARGS` | — | Дополнительные аргументы yt-dlp |
| `YT_DLP_MAX_FILES_PER_REQUEST` | `100` | Макс. файлов из одного плейлиста |
| `YT_DLP_STAGING_DIR` | `<output>/.talmor-tmp` | Временная директория загрузки |
| `WORKER_COUNT` | `2` | Параллельных загрузок |
| `RETRY_BACKOFF_BASE` | `30` | Начальный интервал повтора (сек) |
| `RETRY_MAX_DURATION` | `86400` | Максимальное время повторов (сек) |
| `DIR_SCAN_INTERVAL` | `0` | Интервал сканирования директории (сек, 0 — выключено) |
| `FILE_CHECK_INTERVAL` | `300` | Интервал сверки файлов с диском (сек, 0 — выключено) |
| `FFMPEG_BINARY` | `ffmpeg` | Путь к ffmpeg (извлечение аудио, ID3-теги) |
| `AUDIO_OUTPUT_DIR` | `<output>/audio` | Каталог извлечённых аудиодорожек |
| `OPS_TIMEOUT` | `3600` | Таймаут одной фоновой операции (сек) |
| `LIB_PAGE_SIZE` | `200` | Строк на странице медиатеки |

Параметры загрузчика (прокси, формат, таймаут, доп. аргументы, лимит плейлиста,
размер страницы) можно переопределять на странице «Настройки» без перезапуска —
значения хранятся в базе и перекрывают переменные окружения.

## Особенности поведения

- **Удаление файла** стирает его с диска, но сохраняет запись в БД; исходная ссылка и
  название доступны через `GET /items/deleted`
- **Возврат файла** на прежнее место снова делает его доступным: сканер восстанавливает запись
- **Скрытие** убирает запись с главного экрана, не удаляя данные; можно восстановить.
  Безвозвратное удаление доступно только для скрытых заданий
- **Отмена** доступна для любого задания; «отменить все» останавливает и текущие загрузки
- **Гонка сканер/загрузка** исключена: yt-dlp пишет во временную папку `.talmor-tmp/<jobID>`,
  перемещение в `OutputDir` атомарное
- **Плейлист** превращается в отдельное задание на каждое видео с общим тегом; проверка
  ссылки идёт в фоне и не задерживает ответ ни в вебе, ни в Telegram
- **Медиатека** отдаётся страницами по `LIB_PAGE_SIZE` строк с догрузкой по кнопке

## Разработка

```bash
# Генерация templ-шаблонов
go run github.com/a-h/templ/cmd/templ@v0.3.887 generate ./...

# Сборка
go build ./...

# Тесты (кроме браузерных)
go test $(go list ./... | grep -v tests/e2e)

# Браузерные тесты — нужен Chrome/Chromium
CHROME_PATH=/path/to/chrome go test ./tests/e2e/...
```
