# TalmorGo — Фичи интерфейса и сценарии

> Карта возможностей веб-интерфейса: что умеет каждая часть и зачем ей пользуются.
> Составлено 2026-08-30 по разметке и обработчикам. Устройство — в [SPEC.md](SPEC.md).

Отметки в скобках — как проверено:
**[З]** пройдено в золотом пути браузером на живом экземпляре, **[Т]** покрыто
автотестами, **[—]** не проверялось.

Проверки живут в [tests/golden](../tests/golden): золотой путь, отмена во время
скачивания, оставшиеся сценарии интерфейса и сквозное воспроизведение. Все —
против запущенного приложения, с настоящим yt-dlp и реальным скачиванием из сети.

---

## 1. Добавление ссылки

Поле в шапке, доступно с любого экрана.

- **Скинуть ссылку и забыть.** Вставил адрес ролика, нажал «Скачать» — поле
  очистилось, задание ушло в очередь, страница не перезагружалась. **[З]**
- **Ссылка на плейлист или канал.** Одно задание разворачивается в набор
  отдельных, все помечаются тегом с названием плейлиста. **[Т]**
- **Мусор вместо ссылки.** Браузер не пропустит нессылку (`type="url"`), сервер
  ответит 400 на попытку в обход формы. **[Т]**

## 2. Медиатека: список

- **Посмотреть, что скачалось.** Строки с именем файла, доменом, размером и
  статусом; свежие сверху. **[З]**
- **Большая библиотека.** Выдача постраничная (`LIB_PAGE_SIZE`), внизу кнопка
  «Показать ещё · N из M». **[Т]**
- **Следить за прогрессом, не обновляя страницу.** Строки меняют статус сами:
  сервер шлёт событие, HTMX перезапрашивает список. **[З]**

## 3. Поиск и фильтры

- **Найти по названию.** Поле поиска фильтрует по имени файла, URL, заголовку
  и именам тегов; пустая выдача показывает пустое состояние. **[З]**
- **Отделить музыку от видео.** Сайдбар: «Все / Видео / Аудио». **[З]**
- **Сузить до одной темы.** Клик по тегу в облаке или по тегу в строке
  включает фильтр; повторный клик снимает. **[З]**
- **Много тегов.** Показаны первые пять, остальные — по кнопке «+N ещё». **[З]**

## 4. Теги

- **Пометить одно задание.** Кнопка «＋» в строке. **[З]**
- **Снять метку.** Крестик на чипе тега; тег без заданий исчезает сам. **[Т]**
- **Разметить пачку.** Выделить строки → «Тег» в панели действий; выполняется
  фоновой операцией. **[Т]**

## 5. Коллекции

- **Собрать подборку.** Выделить строки → «В коллекцию» → выбрать или создать. **[З]**
- **Открыть подборку.** Пункт в сайдбаре со счётчиком; включает фильтр и
  показывает полосу «Воспроизвести всё». **[З]**
- **Переименовать или удалить.** Меню «⋮» у пункта сайдбара; видео остаются
  в медиатеке. Переименование **[З]**, удаление **[Т]**

## 6. Массовые действия

- **Выделение.** Чекбоксы в строках и «выбрать все отображаемые»; счётчик считает
  строки, а не задания — у задания бывает несколько файлов. **[З]**
- **Скрыть лишнее.** Убирает строки с глаз, не трогая файлы. **[Т]**
- **Теги аудио пачкой.** Кнопка появляется, только когда выделено одно аудио. **[Т]**
- **Извлечь аудио пачкой.** Кнопка появляется, когда в выделении есть видео;
  одна операция на весь набор, повторы отсеиваются. **[З]**

## 7. Воспроизведение

- **Посмотреть видео.** Клик по строке открывает окно с плеером. **[З]**
- **Свернуть, не прерывая.** Крестик-сворачивание, Escape или клик по подложке
  убирают окно, звук продолжается в нижней панели; «развернуть» возвращает. **[З]**
- **Смотреть с телефона горизонтально.** В ландшафте на сенсорном устройстве окно
  плеера занимает экран целиком, видео вписывается по высоте. Полноэкранный режим
  на iOS отдаётся нативному плееру — Safari не разворачивает произвольные элементы. **[З]**
- **Слушать аудио.** Аудио играет сразу в панели, без модального окна. **[З]**
- **Смотреть подряд.** «Воспроизвести всё» и авто-переход к следующему;
  очередь берётся с сервера по текущему фильтру, а не из видимых строк. **[З]**
- **Перемотка.** Клик или перетаскивание по полосе прогресса. **[З]**

## 8. Действия над файлом (меню строки)

- **Открыть в новой вкладке / скачать.** Прямые ссылки на поток. **[З]**
- **Поделиться.** «Постоянная ссылка» кладёт в буфер адрес `/f/{token}`,
  работающий без авторизации; «Отозвать ссылку» обрывает прежний адрес. **[Т]**
- **Переименовать.** Меняет имя и на диске, и в базе. **[З]**
- **Извлечь аудио.** Из меню строки или из панели действий сразу для набора
  выделенных видео. Теги дорожки берутся из названия видео (исполнитель и
  композиция разбираются по тире или кавычкам), источник скачивания в них не
  попадает; задание помечается тегом «аудио». Для файла без звуковой дорожки
  операция падает — см. TODO. **[З]**
- **Править ID3-теги.** Диалог с галочками «какие поля применять». **[З]**
- **Посмотреть лог.** Вывод последней попытки yt-dlp. **[З]**
- **Удалить файл.** Файл стирается с диска, запись со ссылкой остаётся, поток
  отдаёт 410. **[З]**
- **Скачать повторно.** Для удалённых, потерянных и упавших заданий: файл
  возвращается на диск, запись уходит из списка удалённых. **[З]**
- **Скрыть / вернуть / удалить навсегда.** Последнее доступно только скрытым:
  для видимого задания приходит отказ и файл остаётся цел. **[З]**

## 9. Очередь

- **Что происходит сейчас.** Активные загрузки и фоновые операции одним списком. **[З]**
- **Передумал.** Отмена задания (в том числе прямо во время скачивания: процесс
  yt-dlp убивается, staging чистится, недокачанный файл не остаётся);
  «Отменить все активные» останавливает и текущие загрузки. **[З]**
- **Не получилось.** Повтор упавшего, перезапуск отменённого, лог ошибки.
  Кнопка перезапуска у отменённого задания на месте. **[З]**
- **Убрать с глаз.** Закрыть завершённую операцию; попытка отменить уже
  завершённую отклоняется с пояснением. **[З]**

## 10. Настройки

- **Поменять параметры без перезапуска.** Прокси, формат, таймаут, доп. аргументы,
  лимит плейлиста, размер страницы — перекрывают переменные окружения. **[З]**
- **Скачать закрытое.** Импорт `cookies.txt` в формате Netscape с разбором по
  доменам; домен можно удалить. **[Т]**
- **Прибраться.** «Пересчитать» сверяет файлы с диском и чистит осиротевшие теги;
  «Очистить» безвозвратно убирает упавшие и скрытые задания. **[Т]**

## 11. Доступ

- **Закрыть от посторонних.** При заданном `WEB_TOKEN` — форма входа, cookie на
  год; API принимает и заголовок `Authorization: Bearer`. **[Т]**
- **Работа за Ingress.** Всё работает под префиксом `BASE_PATH`, включая редирект
  на форму входа и постоянные ссылки. **[Т]**

## 12. Telegram (не веб, но тот же сервис)

- **Кинуть ссылку боту.** Сообщение «в очереди» превращается в карточки файлов;
  для плейлиста — сводка. **[Т]**
- **Управлять из чата.** Кнопки «отменить» и «повторить», команды `/status`,
  `/queue`, `/last`, `/search`. **[Т]**
