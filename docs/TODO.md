### ES-модули и делегирование событий

[app.js](web/static/app.js) — около 900 строк глобальных функций, связанных с
разметкой через `onclick` в атрибутах. Мёртвый экран коллекций возник именно
из-за этого: шаблон ссылался на четыре несуществующие функции, и никто не
замечал, пока не полез читать код.

**Что делать:**
- разбить на нативные ES-модули (`player`, `selection`, `filters`, `api`) —
  браузер грузит их сам, сборка не нужна;
- перейти на делегирование по `data-action` вместо `onclick` в разметке;
- обёртка `api()` уже написана и станет одним из модулей;
- заодно вынести стили из `layout.templ` (около 600 строк в одном `<style>`).

## Остаточный долг

### Тестовое покрытие HTTP-обработчиков
Покрыты авторизация, сериализация пустых списков и весь сервисный слой под ними.
Сами обработчики (разбор запросов, коды ответов, события `HX-Trigger`) проверяются
только косвенно — через сервисы и e2e.

### e2e прогоняются только в CI
Тесты берут браузер из `CHROME_PATH` и запускаются отдельным job в GitHub Actions.
На машине разработчика браузера Chrome-семейства нет, поэтому локально они не
проверялись ни разу — первый настоящий прогон будет на CI.

### Плейлист собирается из видимых строк
Клик по строке строит очередь воспроизведения из строк, загруженных в DOM.
После постраничной выдачи это уже не вся медиатека: «Воспроизвести всё» тянет
полный список с сервера, а клик по строке — нет. Стоит свести к одному источнику.

## Сделано

### Архитектура
- **Слой сервисов** — [library.Service](internal/library/service.go) и
  [queue.Service](internal/queue/service.go); HTTP и Telegram стали адаптерами.
- **Единый источник настроек** — [settings.Provider](internal/settings/provider.go)
  вместо трёх расходившихся копий сборки `downloader.Options`.
- **Полосы фоновых операций** — light/heavy, таймаут `OPS_TIMEOUT`, отмена,
  восстановление после рестарта, уборка по сроку `OPS_RETENTION_HOURS`.
- **Read-модель медиатеки** — [media_query.go](internal/repo/media_query.go),
  один построитель запросов вместо пяти копий.
- **Разделение пулов БД** — [db.DB](internal/db/db.go): писатель + пул читателей.
  Заодно выяснилось, что DSN был написан в синтаксисе `mattn/go-sqlite3`, который
  `modernc` игнорирует: WAL, `busy_timeout` и внешние ключи не применялись вовсе.
- **Типизированные SSE-события** — [sse/hub.go](internal/sse/hub.go): темы
  `library`/`queue`/`tags`/`collections` вместо одного «что-то изменилось»,
  публикации склеиваются в окне 300 мс. Браузер обновляет только затронутую часть.
- **Интерфейсы на границах** — `Downloader` и `Clock` в пуле загрузок, `messenger`
  в боте. Появилась возможность проверять backoff, отмену и сценарии бота без
  внешних бинарей и сети.

### Исправленные дефекты
| Что | Где было |
|---|---|
| Кнопка «Скачать» в Telegram отдавала просмотр | `/f/{token}` игнорировал `download=true` |
| Постоянные ссылки ломались при `BASE_PATH` | `CreateLink` использовал `BaseURL` вместо `LinkBase()` |
| Редирект на вход уходил мимо точки монтирования | относительный редирект после `StripPrefix` |
| `WEB_TOKEN` закрывал интерфейс полностью | cookie `_auth` читалась, но никем не выставлялась |
| «Отменить все» не останавливала загрузки | `CancelAll` не трогал процессы yt-dlp |
| `docker-compose` ломал контейнер | `YT_DLP_BINARY=/app/yt-dlp`, а образ ставит в `/usr/bin/yt-dlp` |
| Удаление задания уносило записи о файлах | `Purge` удалял items до проверки `hidden` |
| `job.Hidden` всегда `false` | колонки `hidden` не было в `jobSelect` |
| Пагинация обрывалась на первой странице | не было `Offset` |
| Вернувшийся на диск файл оставался «удалённым» | сканер пропускал любой известный путь |
| Telegram не передавал куки в yt-dlp | своя сборка опций без `CookiesFile` |
| Инъекция в `Content-Disposition` | имя файла вставлялось без экранирования |
| Плейлист качался одним заданием после рестарта | `ResetStale` переводил `checking` → `pending` |
| Зависший ffmpeg блокировал очередь навсегда | не было ни таймаута, ни отмены |
| Облако тегов игнорировало вкладку «Аудио» | `Kind` не учитывался в счётчиках |
| Ошибки удаления коллекции терялись | три `Exec` подряд с `//nolint:errcheck` |
| Экран коллекций был мёртв | шаблон на несуществующих классах и функциях |
| Тег из строки не обновлял облако | `fetch` игнорировал `HX-Trigger` |
| Блокирующий вызов yt-dlp в боте | `FetchPlaylist` ждал до 45 с в обработчике сообщения |
| Пустой список приходил как `null` | клиент падал на разборе пустых коллекций |
| Операции копились в БД без ограничений | не было ни TTL, ни автоудаления |
| Постоянную ссылку нельзя было отозвать | токен выдавался навсегда |
